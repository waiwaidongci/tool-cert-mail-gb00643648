# 001 初始表结构

应用首次启动以 SQLAlchemy 模型创建表与唯一约束，并由 `prepare_columns()` 为既有库补建新增列（不修改既有字段）。升级到修改过字段的版本需要显式迁移。

- `users` 账号角色和加盐密码摘要。
- `datasets` 不可变记录批次，以名称和 SHA-256 去重；`kind` 区分证书班报（certificate）与超差追溯（trace）。
- `runs` 记录参数、数据批次、运行租约、分析结果、导出文件及复核决定；`kind` 沿用数据批次类型，`previous_run_id` 指向做增量重算的对比运行。
- `schedules` 保存定时计划和下一到期时间；`kind` 沿用数据批次类型，每日计划按类型读取最新批次。
- `deliveries` 保存站内分发回执，每次运行最多一个回执。
- `audit_events` 记录登录、数据入库、运行、复核和报表分发动作。

超差追溯结果（批次去向、每次追溯的批次依据与增量重算诊断）保存在 `runs.result` JSON 中，不新增表。
